# tzk-toys

零碎的可视化玩具合集，全部是静态页，浏览器直接打开。

| 目录 | 内容 |
|---|---|
| `3d-demos/` | 5 组 Three.js 场景：自建人物、Sakura 捏脸、机器人、士兵、VRM 动漫角色 |
| `three/` | `sister.html` — 程序化建模的精修版（v5） |
| `svg-art/` | 单张 SVG 插画 + `wrap.html` 预览壳 |
| `_build/` | 批量生成出来的静态页（gw01–…），一次性产物 |
| `_build_sl/` | 上面那批的分片/中间文本 |

## 怎么开

任选一个 `html` 双击即可；`3d-demos` 里带贴图的场景需要同目录素材一起在。

## 说明

这些都是「想到就做」的东西，没有统一框架，别指望目录结构一致。
